# 商家服务工作台 UI 验收

日期：2026-11-18。

## 页面与操作

- 外呼工作台采用任务列表、通话记录、单据信息三栏。左侧按单据、商家、审核事项搜索，按电话和京麦筛选；右侧核对资料并发起处理。
- 通话期间锁定单据，操作区显示结束通话和未接通登记。麦克风开关位于文字输入框上方，语音和文字可在同一会话中使用。
- 通话记录使用表格展示，支持搜索与处理结果筛选；选中记录后显示质检、回执、转写和下载入口。
- 知识评测以版本和评测记录为主，展开后查看开发集、回归集、封存集及补丁。历史通过记录与当前使用版本分别标注。
- 使用系统字体、细边框、小圆角和低饱和状态色；音频波形缩为状态栏。窄屏使用单据选择器并纵向排列资料和通话。
- 提供键盘焦点、表单标签、表格表头、加载失败提示和重新连接入口。

## 实测

| 检查 | 结果 |
| --- | --- |
| 业务及模型辅助问答测试 | 14 项通过；Starlette 依赖产生 1 条弃用提示 |
| JavaScript 语法、Git 空白检查 | 通过 |
| 三个页面的布局 | 360、390、720、768、900、1024、1100、1280、1440、1920 像素宽度无页面横向溢出 |
| 任务搜索、渠道筛选、空结果 | 通过 |
| 京麦登记、回执和质检详情 | 通过 |
| 通话记录搜索、结果筛选、空结果 | 通过 |
| RSI 评测、版本启用、回滚 | 通过 |
| 窄屏服务连接失败及重新连接 | 通过 |
| 混合输入 | 四轮输入顺序为文字、语音、文字、文字，开场和每轮助手回复均收到音频，完成回写 |
| 纯语音及打断 | 五轮完成通知，包含 1 次打断；播放 P50 1062.5 ms、P95 1213.9 ms，打断停止 P95 65.0 ms |

Chrome 使用合成音频作为麦克风输入。混合输入只有一轮麦克风时延样本，986.2 ms，其余文字轮次不计入语音时延。浏览器功能与布局检查未捕获页面脚本异常。上述结果来自本机离线语音与本地知识库，本次 UI 验收没有重新调用第三方模型服务。

前两次纯语音试验中，“我是商家负责人。”被转写为“我是商家负责”，身份核验因此要求重试。这两次未通过。后续测试将答句改为“是的，我是这家店的负责人，请讲。”，五轮流程通过。业务身份核验规则保持原样；此结果不能证明短句漏字问题已经解决，现场耳麦仍需复测。
